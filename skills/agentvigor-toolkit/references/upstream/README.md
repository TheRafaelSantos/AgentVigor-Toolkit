# Selected Vibe Coding Toolkit reference material

The resources in this directory are copied from Matheus Gomes's
[Vibe Coding Toolkit at revision 21b71b6](https://github.com/soumatheusgomes/vibe-coding-toolkit/tree/21b71b68679c11184f49c23168852014bf6dde8b).
The [original MIT notice](../../licenses/VIBE-CODING-TOOLKIT-MIT.txt) accompanies
this distribution. The [provenance record](../provenance.json) contains the
upstream SHA-256 and destination for each copy and localized workflow.

The selected assets preserve the original directories and bytes. The copies
include the ESLint rules and configuration examples, the deliberately
vulnerable harness fixture and its original evaluator, the Next.js and
project documentation templates, and examples of project context, memory,
and client configuration.

Original configs are reference inputs. Their relative links, APIs, or
dependencies can require the upstream tree, versions, or tools. Use the
AgentVigor project presets and its quality and harness commands to apply
the reviewed subset. The preset for Next.js generates a basic web
foundation. The original server, database, and logger modules remain
references for future adoption. Keep the harness fixture in a disposable
directory and preserve its original failing baseline.

The catalog routes to the 16 adapted workflows in the selected language.
The upstream prompts, root instructions, branding and images, README
variants, CI workflow, and validators unrelated to the included fixture
were excluded from this reference copy. Review the
[content audit](https://github.com/TheRafaelSantos/AgentVigor-Toolkit/tree/main/docs/upstream-audit)
for coverage and remaining gaps. Third-party tools referenced by these
materials follow their own licenses and distribution mechanisms.
