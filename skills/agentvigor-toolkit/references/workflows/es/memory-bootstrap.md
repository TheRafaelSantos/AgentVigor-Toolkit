# Memoria del proyecto y traspasos

Mantén conocimiento duradero breve, trazable y recuperable.

1. Encuentra la memoria nativa y los documentos canónicos. Confirma dónde carga el cliente sus instrucciones y cómo recupera un detalle en un contexto nuevo.

2. Registra lecciones duraderas únicamente con fuente, evidencia observada, fecha de verificación y condición de invalidez. Retira entradas obsoletas. Mantén un índice breve y detalles localizables.

3. Registra objetivo, estado real de Git, archivos modificados, comandos, resultados, bloqueos, recursos propios y próxima acción en la tarea. Verifica cada elemento al retomar.

4. Usa almacenamiento externo solo si está seleccionado y autorizado. Deduplica, guarda, vuelve a leer y verifica antes de retirar la entrada original.
