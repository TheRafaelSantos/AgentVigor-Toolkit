# Saneamento de projeto

Meça e organize uma base de código preservando seu comportamento.

1. Confirme o alvo, o estado Git, as instruções, os manifestos e os comandos canônicos de lint, tipos, testes e build. Inspecione scripts antes de executar uma linha de base segura.

2. Liste imports sem uso, código inalcançável, notas antigas e dependências candidatas. Investigue entradas públicas, imports dinâmicos, plugins, peers e reflexão antes de declarar algo sem uso.

3. Separe correções mecânicas de decisões de escopo. Aplique somente itens autorizados em mudanças pequenas e rode a checagem pertinente após cada uma. Preserve alterações alheias.

4. Repita checagens comparáveis. Registre contagens, comandos, falhas e itens que aguardam decisão.
