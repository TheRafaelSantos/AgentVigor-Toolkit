# Memória de projeto e handoffs

Mantenha conhecimento durável enxuto, rastreável e recuperável.

1. Encontre a memória nativa e documentos canônicos. Confirme onde o cliente carrega suas instruções e como recupera um detalhe em contexto novo.

2. Registre lições duráveis somente com fonte, evidência observada, data de verificação e condição de invalidação. Retire entradas obsoletas. Mantenha o índice curto e os detalhes localizáveis.

3. Registre objetivo, Git real, arquivos alterados, comandos, resultados, bloqueios, recursos próprios e próxima ação no registro da tarefa. Confira tudo ao retomar.

4. Use armazenamento externo somente quando selecionado e autorizado. Elimine duplicatas, salve, releia e confirme antes de retirar a entrada original.
