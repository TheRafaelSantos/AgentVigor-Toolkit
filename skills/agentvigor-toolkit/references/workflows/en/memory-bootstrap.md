# Project memory and handoffs

Keep durable knowledge short, sourced, and retrievable.

1. Find native memory and canonical project docs. Confirm where the selected client loads its instructions and how it retrieves a detail in a fresh context.

2. Record durable lessons only with source, observed evidence, verification date, and invalidation condition. Retire outdated entries. Keep the index concise and details discoverable.

3. Keep current objective, actual Git state, changed files, commands, results, blockers, owned resources, and next action in the existing task record. Recheck each on resumption.

4. Use an external store only when selected and authorized. Deduplicate, save, read back, and verify before removing an original entry.
