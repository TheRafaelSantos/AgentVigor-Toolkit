# Security Policy

## Supported versions

Version `1.0.0` is stable for OpenAI Codex. Claude Code is experimental and its
native discovery/invocation are unverified. Check GitHub Releases for the exact
tag and commit; security fixes are prepared against `main`, so consult release
notes before relying on a fix in an older artifact.

## Reporting a vulnerability

Do not publish exploit details, credentials, personal data, or private logs in a
public issue. If GitHub private vulnerability reporting is enabled for this
repository, use **Security → Report a vulnerability**. Otherwise, contact the
maintainer through the [GitHub profile](https://github.com/TheRafaelSantos) and
request a private reporting channel before sending technical details.

Include the affected version or commit, supported platform, impact, and a
minimal reproduction that uses synthetic data. Do not attach secrets or data
from other users or projects. No response-time or remediation-time SLA is
promised.

## Scope and limitations

Reports about the CLI, managed installer, rollback, downloads, hooks, or changes
to global agent files are in scope. Integrations may execute third-party code
under their own licenses and permissions. A synthetic audit or passing CI does
not certify the security of a production environment or third-party service.
The v1.0.0 release does not claim a general scanner/advisory audit or production
security certification.
